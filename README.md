# Cool Finds

A browsable gallery of cool things (well designed, well made, a little funny) picked from a list of favorite shops. Filter by category, shop type and price, and click a photo to go to the shop.

- `index.html` is the whole page (styles and scripts inline).
- `img/` holds the product photos (`<shop>-<NN>.jpg`, 800x600).

The live, interactive version is a Claude artifact. Favorites, 👍/👎 votes, focus notes and "Manage sites" save through the Claude artifact runtime, so they only work there. Opened from this repo (or GitHub Pages), the page still shows and filters every item, but those saving features stay off.

To view locally, open `index.html` in a browser.
